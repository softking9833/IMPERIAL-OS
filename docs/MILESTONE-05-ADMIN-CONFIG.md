# Milestone 5 — Admin Config (Business Empowerment)

## Goal

Give the Managing Director configuration tools so IMPERIAL can change training, commercials, KPI structure and day rates without developer intervention.

## Delivered

- Admin Config page with tabs:
  - Curriculum create + add lessons
  - Campaign commercials (sale value, realised statuses, payment days)
  - KPI targets + campaign funnel editor
  - Associate day rates (effective-dated)
  - Business rules (EOD deadline + rule list)
- Admin APIs under `/admin/*`
- Home MD action linking to Admin Config

## Demo path

1. Sign in as MD
2. Open **Admin Config**
3. Add a lesson to Field Readiness curriculum
4. Change Energy Switch sale value / funnel
5. Update Associate day rate
6. Save KPI targets
