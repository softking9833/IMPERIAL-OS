# Milestone 2 — Learn + Performance

Builds on Foundation to deepen two Core Operating Loops.

## Goal

1. **Learn Loop** — real lesson content (text/video) + quizzes, not just “mark complete”
2. **Performance Loop** — KPIs and Predicted vs Actual profitability from field data

## Delivered

- Lesson content model linked to Field Readiness / ongoing learning
- Associate Learn experience (read lesson, take quiz, track progress)
- Admin Learn content list / create lesson
- Performance summary: doors, conversations, sales, conversion rates
- Predicted Revenue / Profit vs Actual (Realised) Revenue / Profit
- MD can update sale status (processing → paid / cancelled)

## Demo path

1. MD opens **Learn** → review seeded lessons
2. Associate Loop / Learn → complete a lesson + quiz
3. Associate records field activity + sales (Milestone 1)
4. **Performance** → see KPIs and predicted profit
5. MD updates a sale to `PAID` → actual/realised profit updates
