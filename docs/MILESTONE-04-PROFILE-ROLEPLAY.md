# Milestone 4 — Profile + Roleplay

## Goal

1. **Profile** — one identity view with timeline, deployment, day rate, progression snapshot
2. **Roleplay Loop** — practise → submit → leader review → improve

## Delivered

- Profile API + page (edit name, timeline, roleplays, performance snapshot)
- Roleplay requirements (seeded + MD can create)
- Associate submission
- MD review queue (approve / return with feedback)
- Home actions include pending roleplays / review queue

## Demo path

1. **Roleplay** → Associate practice → submit Door Opening script
2. Switch to **MD review queue** → Approve or Return
3. Open **Profile** → see timeline + recent roleplays
4. **Home** → primary actions update for roleplay status
