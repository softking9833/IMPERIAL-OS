# Milestone 3 — Home + Richer Field

## Goal

1. **Home** — every user sees what to do next
2. **Field** — callbacks + End of Day report on top of doors/sales

## Delivered

- Home priority actions (MD and Associate)
- Field day screen with activity, sales, callbacks, EOD
- Callback create / complete
- End of Day submit (auto-fills today's activity counts)

## Demo path

1. Open **Home** as Associate → follow primary action
2. Open **Field** → save doors, add callback, record sale
3. Submit **End of Day**
4. Return to **Home** → primary action updates
5. As MD, Home shows approvals / performance priorities
